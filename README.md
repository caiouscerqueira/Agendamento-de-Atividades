# Agendamento-de-Atividades
O sistema em questão foi projetado para atuar como uma solução robusta na gestão e resolução de conflitos em cronogramas de eventos, como treinamentos corporativos e palestras acadêmicas. Sob a ótica da ciência da computação, a aplicação aborda o clássico Interval Scheduling Problem (Problema de Agendamento de Intervalos).
